# Lens Applications

:::note[Disclaimer]
The following content is not included in the paper and is used as illustration only.
:::

Each page below reads one audited claim through the framework's five lenses — philosophy of
science, neuroscience, pharmacology, measurement theory and mechanistic interpretability — as an
illustration of how the same criteria divide by discipline and what each field's tradition asks
of the evidence.

Criterion statuses match the paper's audit records. The lens grouping, the key distinctions and
the matrices around them are exploratory, and no verdict rests on them. The audits themselves
are under [Case Studies](/mechanistic-validity/framework/audits/).
